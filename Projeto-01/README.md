# Projeto 01 - Testes de E-commerce
## Objetivo
Testar funcionalidades de um e-commerce
## Cenários de teste
### CT-01 - Login com dados válidos
**Passos**
1. Informar usuário válido
2. Informar senha válida
3. Clicar em "Entrar"

**Resultado Esperado:**
Usuário autenticado com sucesso:
### CT-02 - Login com senha inválida
**Passos**
1. Informar usuário válido
2. Informar senha incorreta
3. Clicar em "Entrar"

**Resultado Esperado:**
Mensagem de erro exibido.
